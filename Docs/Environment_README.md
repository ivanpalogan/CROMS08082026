# CROMS demo / test environment - how to use it

A second, fully working copy of CROMS (schema `croms_demo`) for demonstrations, tests and staff training. The live
registry (`croms`) is never written. Design and reasons: `Docs\Environment_Design.md`.

## Quick start

```powershell
cd Scripts\Environment
.\New-DemoEnvironment.ps1 -Confirm         # once: schema + account + reference data + 2 logins (passwords shown ONCE)
..\SampleData\Run-SampleData.ps1 -Target Demo     # optional: fictional sample records (see Scripts\SampleData\README.md)
.\Start-DemoEnvironment.ps1                # opens CROMS (the launcher) against the demo; look for the orange badge
```
Close CROMS.exe, the kiosk and the display first if Visual Studio is building (they lock `bin\Debug`).
Build first with `MSBuild CROMS.sln -p:Configuration=Debug` (VS 2019).

## Scripts (all in `Scripts\Environment`, PowerShell 5.1, no password inside any of them)

| Script | What it does | Needs |
|---|---|---|
| `New-DemoEnvironment.ps1` | create schema (same charset/collation as live), load the live **structure** (views rewritten to point at the demo), create the restricted account, copy the reference data, create `demoadmin` / `demostaff`, record the migration baseline | `-Confirm`; `-Recreate` to rebuild an existing one |
| `Apply-Migrations.ps1` | apply `CROMS\Database\NN_*.sql` newer than the baseline, in numeric order, once each (ledger table `_env_migrations`); second run changes nothing | `-Confirm` |
| `Reset-DemoEnvironment.ps1` | empty the 35 transactional tables, reload the reference data; the two logins stay; safe to run twice | `-Confirm` |
| `Refresh-FromLive.ps1` | optional live -> demo reload of the **reference** tables only (personal data is not copied; see design note section 5) | `-Confirm` |
| `Remove-DemoEnvironment.ps1` | drop the schema, the MySQL account, the DPAPI file and the local demo folder | `-Confirm` |
| `Start-DemoEnvironment.ps1` | copy the built apps to `%LOCALAPPDATA%\CROMS\Demo\App`, write demo `.exe.config` files, start `-Launch Main` (default) / `Kiosk` / `Display` / `All` / `None` | the environment exists |
| `Test-DemoEnvironment.ps1` | run `CROMS.MarriageTest` modes against the demo and prove `croms` is unchanged (row counts of every table + table/column/view counts) | built `CROMS.MarriageTest.exe` |

Every destructive script prints the schema and host it will change, and **refuses** `croms`, an empty name and any
name not starting `croms_demo` / `croms_test`. Nothing defaults to `croms`.

## Configuration

| Item | Where | Value |
|---|---|---|
| Schema | MySQL on this PC | `croms_demo` |
| MySQL account | `croms_demo_app`@`localhost` | DML on `croms_demo`.* only; password in `%APPDATA%\CROMS\demo-env.cfg` (DPAPI, current Windows user) |
| App logins | `users` in `croms_demo` | `demoadmin` (Admin, must change password at first sign-in), `demostaff` (Staff). Generated passwords are printed once by `New-DemoEnvironment.ps1` |
| Executables + configs | `%LOCALAPPDATA%\CROMS\Demo\App` | generated; the live `bin\Debug` configs are never edited |
| Dev servers (save-API, scanner, claimapp) | - | **off** in the demo (`IonicAutoStart=false`) |

## What is NOT copied

Scans and photographs, signatures, uploaded IDs, phone pairing (`form97_capture_*`), the learning library, staff
biodata, audit history, and every registry/transaction table. The demo's people are generated by `Scripts\SampleData`.

## Known limits

- Demo database = this PC only (`localhost`). A kiosk/display on another PC cannot use it.
- Shared per-user files (`%APPDATA%\CROMS\server.cfg`, `mobile.cfg`, `print-align.cfg`) are read by the demo too;
  `Start-DemoEnvironment.ps1` stops if `server.cfg` names a remote host.
- Adding a migration `87+`: build, then `Apply-Migrations.ps1 -Confirm`; the live schema is not touched by it.
- Master-file test entries in the live database are filtered out of the demo copy (not deleted from live).

## Test commands

```powershell
.\Test-DemoEnvironment.ps1 -Modes @('','--birthtest','--recycle','--envbadge')   # default suite expects PASSED 77
```
